# 📮 Vintage Envelope — Letters from Another Time

A vintage-inspired airmail envelope recreated with HTML, CSS, and Bootstrap 5.

This project celebrates the charm of traditional letter writing through warm paper tones, vintage postage stamps, postal details, and a classic editorial style.

## ✨ Features

- **Vintage-inspired design** with warm ivory, burgundy, sage green, and terracotta accents.
- **Airmail envelope layout** with sender and receiver addresses.
- **Postage stamp details** using local images.
- **Responsive styling** for desktop and mobile screens.
- **Custom typography** using Google Fonts.
- **Bootstrap 5** for layout utilities and responsive structure.
- **Semantic HTML** with descriptive document metadata and accessible image text.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3
- Google Fonts

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

The envelope images are stored locally in the `pictures/` directory. Google Fonts and Bootstrap are loaded from external CDNs, so an internet connection is needed for those resources.

## 🎨 Design Approach

The visual direction combines the nostalgic feeling of traditional correspondence with a clean, modern layout.

The color palette includes:

- **Ivory:** warm paper-inspired backgrounds.
- **Burgundy:** classic postal accents.
- **Sage green:** subtle vintage details.
- **Terracotta:** warm decorative highlights.
- **Ink:** readable, understated text.

The design uses custom CSS alongside Bootstrap utilities to maintain a distinctive appearance without relying on a generic component-library aesthetic.

## 📚 What I Practised

- Structuring a webpage with semantic HTML elements.
- Combining Bootstrap with custom CSS.
- Organizing CSS through reusable custom properties.
- Creating responsive layouts with media queries.
- Working with local image assets and alternative text.
- Using typography, color, and spacing to establish a visual identity.
